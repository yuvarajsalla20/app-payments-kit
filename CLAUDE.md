# Rules for this kit

- Every word this repository shows or publishes must be professional and consistent: captions, taglines, sub-lines, placeholders, notes, messages and buttons, and equally the README, changelog, code comments, commit messages and pull requests. Follow the "Writing rule" in app-settings-kit's README (https://github.com/yuvarajsalla20/app-settings-kit#writing-rule-every-word-is-professional): Title Case for titles, rows and buttons; calm, complete sentences for captions and messages; "e.g.," for examples; no chatty fragments, slang or exclamation marks.
- Keep the README current: the "Current version" line, the install pin example and the changelog change in the same pull request that raises the version.
- Apps never override kit words or layout: change the kit default instead (a major version when the change is visible).
